よりみち日和 v2.2.0 — 再訪登録・飲食カテゴリ強化
2026年10月27日

【正本】
GitHub main にある v2.1.0 の5ファイルを比較し、内容が一致した状態から改修しています。
陣取りマップ v2.1.0、既存データ、写真、動画、カレンダー、ピン地図を維持します。

【機能】
1. 思い出アルバムの「いつものお店・場所へ再訪」から以前行った場所を選び、再訪を登録。
2. 思い出カード、訪問一覧、訪問詳細からも「♻️ 再訪」を押せます。
3. 以前の店名・住所・カテゴリ・位置・関連リンク・日帰り宿泊区分を引き継ぎ、訪問日・その日の感想を新たに入力。
4. 写真は「以前の写真をそのまま使う（参照共有）／新しい写真を登録／写真なし」から選択。
   以前の写真はコピー・移動・削除せず、Firestore写真IDを参照します。
   ※写真の参照元への読み取り権限は既存のFirestoreルールに従います。
5. 訪問履歴、訪問回数を場所ごとに表示（既存ログも集計対象）。
   日付が同じ記録がある場合は、保存前に確認。
6. 「外食・グルメ」に「カフェ」「カフェ・喫茶」「中華」を表示。
   Firebaseに保存済みのカテゴリがあっても不足分を補って表示します。
7. 保存時は再訪1回を新規の logs ドキュメントとして追加。過去の訪問記録は上書きしません。

【公開手順】
1. 公開前にGitHubの現行リポジトリをZIPバックアップしてください。
2. このZIPを解凍してください。
3. https://github.com/webrich60/Yorimichi-LifeLog を開き、mainブランチのルートで
   Add file → Upload files を選びます。
4. 以下の5ファイルをアップロード（同名ファイルは更新）。
   index.html
   app.js
   styles.css
   prefecture-map.js
   prefecture-map.css
5. Commit changesを押してください。
6. GitHub Pagesの反映後、スマホの画面を更新し、アプリのバージョンがv2.2.0か確認してください。
   キャッシュが残る場合は再読み込みしてください。キャッシュ削除で保存データを消さないよう注意。

【確認項目】
・以前の中華料理店を選び、別の日付で「前の写真を使う」→保存→訪問数が増える
・別の日付で「新しい写真を登録」→写真を選ぶ→保存→その日だけ新しい写真が付く
・アルバム→記録を見る→「訪問履歴」から過去の日付を選べる
・「外食・グルメ」の小カテゴリにカフェ／中華が表示される
・以前の写真、記録、陣取りマップが残っている

【運用上の注意】
写真は1回の訪問につき最大5枚。写真を再利用する場合、元の写真IDへの参照が保存されます。
元の写真データを個別に完全削除すると、参照先の写真が表示できなくなる可能性があります。
既存アプリの「ゴミ箱へ」はログの論理削除であり、元写真の完全削除はしません。
日付とカテゴリは自由に編集できます。同じチェーンの別店舗は「同じ場所のまとめ名」を
店舗別に設定すると回数をより正確に分けられます。
